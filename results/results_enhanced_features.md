# 增强物理特征 + 消融结果

**日期**：2026-10-10
**任务**：SOH 回归，留一电池交叉验证（跨温度泛化）

## 消融结果
| 特征集 | RMSE | R² |
|---|---|---|
| 简单物理特征（V_mean/V_std/V_slope/T_mean） | 0.1349 | **−0.94** |
| 增强物理特征（+电压平台斜率/IR drop/放电时长/温升等） | 0.0422 | **0.810** |
| 增强物理 + cycle_idx | 0.0414 | 0.815 |

## 特征重要性（增强物理，无 cycle_idx）
- capacity 0.956（主导）
- V_mean 0.038
- T_mean 0.005
- 其余（V_drop / V_plateau_slope / duration 等）≈ 0

## 两个关键结论
1. **增强特征把纯物理特征从 R² −0.94 抬到 0.81**——特征工程价值显著。
2. **但 capacity 占 95.6% 重要性**——这是 SOH 的定义成分（soh = capacity/c0），说明在 NASA 数据上 SOH 主要由容量本身决定，电压/温度/内阻等间接物理特征贡献微弱（随老化变化太小）。

## 对论文定位的判定
「可解释物理特征（不含容量）预测 SOH」在 NASA 数据上**信息量不足**（间接特征单独预测 R² 为负）。可行且诚实的定位改为：
- **核心 = 跨温度泛化 + 轻量可解释树模型**（留一电池 CV 的 RMSE 0.042 / R² 0.81 已具可写性）
- **方法贡献 = 特征工程消融**（简单统计 → 增强物理，R² 大幅提升）
- **可解释性 = SHAP 诚实揭示容量主导**（而非硬拗"物理特征驱动"）
- 放弃「早期循环特征预测远期」与「纯间接特征预测 SOH」两条走不通的路。
